# kenni

An early iOS-only audiobook player built with Expo/React Native.

## MVP
- Import audio files from iPhone Files
- Download direct HTTPS audiobook audio files to local storage
- Offline playback, resume position, skip controls and playback speed

## Setup
```bash
npm install
npx expo start
```

## Limitations
Source code is untested and no iOS build has been produced. Torrent/magnet links, DRM, chapter extraction, sleep timer, and search catalogs are not yet implemented. Download only books you have permission to access. No paid DeepSeek API calls have been made.
